# Release notes: career pathing, training, resume studio, documents, booking, note summaries

Everything here is built on branch `claude/upbeat-mccarthy-qbycdp`. None of it has been run against a real database or the real O*NET/BLS downloads from the environment it was built in, so the first deploy is the first real test. Typecheck, lint and the full unit suite pass.

## Before deploying, in this order

1. **Run the SQL** (all additive, re-runnable, each in `prisma/manual/`):
   `2026-10-14-career-taxonomy.sql`, `2026-10-14-training-matching.sql` (needs the first),
   `2026-10-14-resume-studio.sql`, `2026-10-14-document-requests.sql`,
   `2026-10-14-coach-booking.sql`, `2026-10-14-coach-note-summaries.sql`.
   Or `npx prisma db push` per `docs/DATABASE_SCHEMA.md`.
2. **Create a private Supabase Storage bucket** named `requested-documents` (not created from here).
3. **Deploy.**
4. **Load the data** (the Pivot Tool shows "Occupation data isn't loaded yet" until step a is done):
   a. `npm run careers:import-onet -- --dir <O*NET text folder> --version <n> --dry-run`, then without `--dry-run`
   b. `npm run careers:import-bls -- --oews <csv> --wage-year <yyyy> --projections <csv>`
   c. `npm run careers:tag-courses -- --dry-run`, then without
   d. per state, optional: `npm run careers:import-training -- --file <csv> --state XX --source "<name, date>"`
   See `docs/CAREER_TAXONOMY.md` for sources and caveats.

## What shipped

| Item | Where | Notes |
|---|---|---|
| Skills taxonomy and Pivot Tool | `/dashboard/pivot` | O*NET + BLS; skill-gap suggestions now start from the target occupation's O*NET tools and knowledge |
| Training matching | on each Pivot option | catalog courses tagged to skills; state funded-program lists where loaded |
| Resume studio | `/dashboard/resume/studio` | edit, keep a draft per role, writing checks, ATS text view, keyword check, PDF/Word download |
| Requested documents | `/dashboard/documents`, coach client page | request, upload, accept or send back; private bucket |
| Coach booking | `/support/coach/booking`, `/dashboard/book-session` | weekly hours, slots, Meet links on the shared calendar |
| Coach note summaries | coach client brief | on-demand AI summary, cached, capped |

## Costs and one-time effects

- **Skill-gap suggestions:** each candidate's cached suggestions are regenerated once, the first time they are viewed after the taxonomy is loaded (one model call each). Candidates are unaffected until the data is loaded.
- **Coach note summaries:** on-demand only, 30 per coach per day, see `docs/OPEN_ITEMS.md`.
- **Pivot Tool:** no model calls. Local-openings counts use the existing Adzuna cache and its budget, and only show if `ADZUNA_INSIGHTS_ENABLED` is on.

## Known gaps

See `docs/OPEN_ITEMS.md`. In short: no per-coach calendar sync (booking cannot see a coach's own appointments), no AI import of an uploaded resume into the studio, no institution/employer document requesters, no ETPL data loaded for any state, and the importers have not been run on the real files.
