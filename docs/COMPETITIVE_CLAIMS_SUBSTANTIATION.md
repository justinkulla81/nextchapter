# Competitive claims substantiation file

Per Partners Master Build Script §D3 ("One rule above all: every competitive
claim must be documentable. Keep a substantiation file with the source for
every comparative statement on the site... When a competitor's counsel
writes — and at some point they will — the file is the entire defense.")
and §D6 ("Comparison pages need a review date... a stale claim is the one
that draws a letter.")

**This file's current status: not launch-ready.** Every claim below is
sourced to the Partners Master Build Script itself (`docs/specs/NextChapter_Partners_Master_Build_Script.md`),
which states in its own §A2.1 that its competitor pricing table is
"informed estimates, not cited sources." No independent, current,
third-party verification of LHH / Randstad RiseSmart / Careerminds / INTOO
pricing, features, or market position has been done. **A real marketing or
legal reviewer must independently verify every row marked "NEEDS
VERIFICATION" against a current, citable public source (vendor pricing
page, analyst report, public filing, dated review) before any of these
pages goes live to real prospects or gets indexed for real traffic.**

**Review cadence:** quarterly, per §D6. This file has no prior review, so
the first review date below defaults to 90 days from the date this file was
created (2026-08-15) — **next review due 2026-11-13.** Update this date on
every real review, and re-verify every row on that date regardless of
whether anything changed publicly, since a stale claim (not just a false
one) is what §D6 warns creates exposure.

## What "NEEDS VERIFICATION" means before launch

For each row flagged above, a real reviewer should, before these pages
receive real prospect traffic or get submitted to search engines for
indexing:

1. Find a current, citable public source for the underlying fact (vendor
   pricing page, an analyst report such as Everest Group/IBISWorld, a dated
   third-party review, a public filing, or a documented sales conversation
   with a named, consented source).
2. Either replace the spec-sourced citation in this file with the new,
   independently verified source, or soften the on-page language until it
   is no longer a specific comparative claim (e.g., move from a number to
   "typically," or remove the row).
3. Re-run this review on every quarterly cycle even if nothing changes —
   per §D6, a stale claim is the risk, not only a false one.
