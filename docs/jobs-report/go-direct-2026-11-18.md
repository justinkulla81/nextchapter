## Did last cycle's sources reach the board?

Yes, in part. A bounded query (direct, approved, live rows created since 2026-11-13 under the 129 verified employer names, capped at 20,000 rows) found 4,717 rows for 78 of the 129 employers. The count includes direct rows from any other source, so it is an upper bound. The crawler's `aggregator_direct_20261113.yaml` holds 55 enabled sources; the 29 SmartRecruiters ones are held (`enabled: false`).
