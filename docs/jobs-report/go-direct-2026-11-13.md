## What verification caught

A board at an address equal to the employer's name is not proof it is theirs. The first pass called 174 "high confidence"; checking each board's own name or postings rejected collisions such as Google (the Workday board `google/GOCJobs` is Google Operations Center, 60 jobs, almost all in India), Linkedin (two test postings), Apex Systems (board is "Apex Eye"), System One (board is "System"), Relativity (board is Relativity Space, a rocket company), General Dynamics, Charles Schwab, Applied Materials. One more (Icon, an Ashby startup board, not the ICON research firm) passed the heuristic and was removed by hand. The check for Lever, Ashby and Workday is a heuristic (the name in at least 2 of 5 postings, a board of 5 or more jobs, US postings for Workday), so the crawler's dry run must still confirm the company on each board.
