# Personalization spine

Generated by `npm run docs:spine` from `src/lib/personalization/spine.ts`. Do not edit by hand.

Personalization is the foundation for every journey and stage. Each question below is asked because its answer drives something we do: the weekly plan, learning and development, networking, the opportunities we show, the report or the coaching. Nothing is asked that does not drive something, and a test checks that every file named as reading an answer really reads it.
