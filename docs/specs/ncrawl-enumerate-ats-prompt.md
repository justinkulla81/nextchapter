Goal: find roughly 1,500 to 3,000 more employers whose own public job boards the crawler can read, to add about 100,000 more live direct US white-collar jobs (knowledge workers, professional and managerial occupations, SOC major groups 11 to 29). Dry run first; do NOT import into production until the owner approves the counts. Work in this repo (`nextchapter-jobs`).

Context
- The NextChapter board has about 235,000 live US direct jobs (jobs on the employer's own career system, verified in the last 14 days), about 65% white-collar by SOC. About 15% of white-collar postings name an AI skill or tool. There is no stored "college degree required" flag.
- The crawler already reads about 1,087 Workday sources plus other adapters. The 33 largest Jooble employers and 25 more (tier 3) are in `docs/jobs-report/jooble-to-direct-phase2.md` in the nextchapter repo and are handled separately.
- Rule: career site and job system only, public endpoints only, identified user agent, a polite rate (a few requests a second at most across all hosts, one request in flight per host). US jobs only. Do not change the seniority screen; report what it drops by level, and flag white-collar titles dropped for lacking a level word.

Do this
1. **Enumerate employers per job system** from the Common Crawl index (https://index.commoncrawl.org, CDX API, the latest few crawls, `matchType=domain`, `output=json`, `fl=url`, deduplicate by host and path prefix). Systems and address patterns: Workday (`<tenant>.wd<N>.myworkdayjobs.com/<site>`), Greenhouse (`boards.greenhouse.io/<token>`, `job-boards.greenhouse.io/<token>`), Lever (`jobs.lever.co/<token>`), Ashby (`jobs.ashbyhq.com/<token>`), SmartRecruiters (`jobs.smartrecruiters.com/<company>`), iCIMS (`careers-<x>.icims.com`), Oracle HCM (`*.oraclecloud.com/hcmUI/CandidateExperience/<lang>/sites/<site>`), Taleo (`<x>.taleo.net/careersection/<section>`), UKG (`recruiting*.ultipro.com`), Paylocity, Dayforce, Jibe. If the CDX API is slow or capped, say so and page it; do not hammer it.
2. **Remove what we already have**: every tenant already a crawler source (compare normalized tenant and token), the 33 and 25 employers above, and staffing and recruiting firms (their postings are the recruiter's own listings, handled separately).
3. **Measure each remaining employer cheaply**: one public request to the system's list endpoint for the total, and where the system supports a location filter, the US count. Record tenant, site, total and US count. Skip employers that return nothing.

6. List the job systems that have employers but no adapter in the crawler yet, ranked by the kept jobs each would unlock (Phenom, Eightfold, SuccessFactors, iCIMS, Oracle HCM, Taleo, UKG first).
7. Add the sources in batches of 100 employers, dry run each batch, and report the live direct count before and after the first batch's sync.

Report back: the ranked table (a file, not the chat), the cumulative curve, the dry-run funnel for the first 200, the AI-skill and degree shares, the missing adapters, and anything you could not measure. Do not import to production, and do not guess numbers.
